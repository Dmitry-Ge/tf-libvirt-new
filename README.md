### Пример для разворачивания виртуалок локально на линуксе с libvrit + qemu

Я использую это для тестирования Ansible playbooks
Этот сценарий поднимает заданное количество виртуалок локально. Собственно единственная
проблема - провайдер libvirt не умеет отдавать ip адрес который выделяется на
виртуалку, поэтому после создания его придется проверить руками
``` virsh net-dhcp-leases default ```
